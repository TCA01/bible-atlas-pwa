# Product Requirements Document (PRD): Global Interactive Bible App (PWA)

> **문서 목적**: 이 문서는 전 세계 기독교인을 위한 다국어·인터랙티브 지리/역사 해설 성경 앱(PWA)의 제품 요구사항 정의서입니다. AI 코딩 모델(Hydrogen)이 제품의 기능, UX, 문화권별 읽기 규칙, 수용 기준을 정확히 이해하고 구현할 수 있도록 작성되었습니다.

---

## 1. 제품 비전 및 핵심 가치 (Product Vision)

### 1.1 문제 정의
기존 성경 앱은 대부분 단순 텍스트 뷰어에 머물러 있어 다음과 같은 한계가 있습니다:
1. **지리적·역사적 맥락 단절**: 성경 속 고대 지명(예: 다메섹, 앗수르, 빌립보)이 현재 어느 나라의 어떤 도시인지 직관적으로 알기 어렵습니다.
2. **문화권별 읽기 습관 미반영**: 대부분의 앱이 서구권 가로쓰기(`LTR`) UI만 제공하여, 일본어 세로쓰기(`縦書き`, `vertical-rl`)나 아랍어 우→좌(`RTL`) 독자의 자연스러운 읽기 경험을 지원하지 못합니다.
3. **고정된 접근성**: 다양한 연령대와 시력 조건을 가진 전 세계 사용자들이 글씨 크기·줄간격·배경 테마를 세밀하게 조절하기 어렵습니다.

### 1.2 핵심 차별점
- **Interactive Biblical Atlas & Inline Commentary**: 성경 본문 속 지명을 클릭하면 즉시 인터랙티브 지도가 열리며 **고대 지명 ↔ 현대 국가·도시명** 비교(예: `다메섹 → 시리아 다마스쿠스`), 시대별 여정, 역사·지리 해설을 9개 언어로 제공합니다.
- **Culturally Native Reading Engine**: 언어에 따라 `LTR` (가로쓰기), `RTL` (아랍어 우→좌), `Vertical-RL` (일본어 세로쓰기, 중국어 번체 선택)을 네이티브 수준으로 지원합니다.
- **Global 9-Language + Multi-Version Support**: 영어(기본)에서 **NIV, ESV, NRSV, KJV** 4종 역본을 모두 지원하며, 총 9개 언어권으로 즉시 전환 가능합니다.
- **Local-First PWA**: 로그인 없이 즉시 사용 가능하고, 퍼블릭 도메인 역본과 지도/해설 데이터는 오프라인에서도 작동합니다.

## 2. 지원 언어 및 성경 역본 매트릭스 (9 Languages & Versions)

### 2.1 지원 언어 목록 (총 9개 언어, 기본 언어: 영어 `en`)

| 순서 | 언어 | Locale 코드 | 기본 읽기 방향 | 지원 읽기 방향 옵션 | 기본 내장 역본 (Public Domain / Open) |
| :-: | :--- | :--- | :--- | :--- | :--- |
| 1 | **English (기본)** | `en` | `ltr` | `ltr` | **KJV** (내장) + **NIV, ESV, NRSV** (API 어댑터) |
| 2 | **한국어 (Korean)** | `ko` | `ltr` | `ltr` | 개역한글(KRV, PD) + API 확장 |
| 3 | **日本語 (Japanese)** | `ja` | **`vertical-rl`** | `vertical-rl` / `ltr` 전환 | 口語訳 (Kougo-yaku, PD) |
| 4 | **中文 (Chinese)** | `zh-Hans` / `zh-Hant` | `ltr` (간체) / `ltr`·`vertical-rl` (번체) | `ltr` / `vertical-rl` (번체 선택) | 和合本 (CUV, PD - 간체/번체) |
| 5 | **Español (Spanish)** | `es` | `ltr` | `ltr` | Reina-Valera 1909 (RV1909, PD) |
| 6 | **Português (Portuguese)** | `pt` | `ltr` | `ltr` | Almeida Corrigida Fiel / Livre (PD) |
| 7 | **Français (French)** | `fr` | `ltr` | `ltr` | Louis Segond 1910 (LSG, PD) |
| 8 | **Deutsch (German)** | `de` | `ltr` | `ltr` | Lutherbibel 1912 (LUT1912, PD) |
| 9 | **العربية (Arabic)** | `ar` | **`rtl`** | `rtl` | Smith & Van Dyck (SVD, PD) |

> **참고 (중국어 간체/번체 처리)**: 언어 선택기에는 9개 언어(`English`, `한국어`, `日本語`, `中文`, `Español`, `Português`, `Français`, `Deutsch`, `العربية`)로 노출하며, `中文` 선택 시 서브 옵션으로 간체(`zh-Hans`) / 번체(`zh-Hant`)를 전환할 수 있습니다.

### 2.2 영어 역본 4종 지원 정책
사용자가 요청한 **NIV, ESV, NRSV, KJV** 4종을 모두 지원합니다:
- **KJV (King James Version)**: 퍼블릭 도메인. 로컬 JSON/SQLite에 완전 내장되어 API 키 없이도 즉시 동작하며, 오프라인 캐싱이 100% 허용됩니다.
- **ESV (English Standard Version)**: Crossway ESV API 어댑터 연동. 약관에 따라 서버 프록시로 호출하고, 클라이언트 영구 오프라인 저장(`allowOfflineCache: false`)은 제한합니다.
- **NIV (New International Version)** & **NRSV (New Revised Standard Version)**: API.Bible (또는 출판사 공식 API) 어댑터 연동. API 키 미설정 시 UI에 "API 연동 필요 / KJV로 보기" 안내 폴백을 제공합니다.

## 3. 문화권별 읽기 경험 & 타이포그래피 요구사항

### 3.1 읽기 방향 (Writing Mode & Direction)
1. **일본어 세로쓰기 (`vertical-rl`)**:
   - 일본어(`ja`) 선택 시 기본 모드는 `vertical-rl` (위에서 아래로 읽고, 줄은 오른쪽에서 왼쪽으로 진행).
   - 장 내 스크롤: 마우스 휠(상하) 입력을 가로 스크롤(우→좌)로 자연스럽게 매핑하며, 터치 스와이프는 좌우 스와이프로 동작.
   - 절 번호(`1`, `2`, `12` 등)는 `text-combine-upright: digits 2`를 적용해 세로 줄 안에서 정갈하게 가로로 조합.
   - 헤더의 읽기 모드 토글 버튼으로 사용자가 언제든 `세로쓰기(縦書き)` ↔ `가로쓰기(横書き)` 전환 가능.
2. **중국어 번체 세로쓰기 옵션**:
   - `zh-Hant` 선택 시 가로쓰기를 기본으로 하되, 일본어와 동일한 `vertical-rl` 토글 옵션을 제공.
3. **아랍어 우→좌 (`rtl`)**:
   - 아랍어(`ar`) 선택 시 `<html dir="rtl" lang="ar">` 적용.
   - 네비게이션 바, 이전/다음 장 화살표 방향, 사이드 패널 열림 방향, 여백 등이 CSS Logical Properties(`ps-*`, `pe-*`, `ms-*`, `me-*`)를 통해 자동 미러링.
4. **가로쓰기 (`ltr`)**:
   - 영어, 한국어, 중국어 간체, 스페인어, 포르투갈어, 프랑스어, 독일어에 적용.

### 3.2 타이포그래피 및 테마 컨트롤 (실시간 반영)
리더 상단 `Aa` (표시 설정) 버튼을 누르면 드로어/팝오버가 열리며 아래 항목을 실시간 조절하고 `IndexedDB`에 즉시 저장합니다:
- **글씨 크기 (Font Size)**: `14px` ~ `32px` (2px 단위 슬라이더 또는 `-` / `+` 버튼, 기본값 `18px`)
- **줄 간격 (Line Height)**: `1.5` (좁게), `1.8` (보통, 기본), `2.1` (넓게)
- **서체 스타일 (Font Family)**: `Serif` (명조/세리프 계열, 성경 읽기 최적화 기본값) vs `Sans` (고딕/산세리프 계열)
- **테마 (Theme)**:
  - `Light` (순백 배경 `#FFFFFF`, 짙은 회색 텍스트 `#1A1A1A`)
  - `Sepia` (따뜻한 종이 질감 `#F5EFE6`, 갈색 계열 텍스트 `#3D3226`)
  - `Dark` (눈의 피로를 줄이는 다크 `#121417`, 부드러운 회백색 `#E5E7EB`)
- **절 번호 표시 / 지명 하이라이트 표시 토글**: 집중 독서 시 지명 밑줄을 일시적으로 끄고 켤 수 있는 토글.

## 4. 인터랙티브 지도 & 역사·지리 해설 요구사항

### 4.1 본문 인라인 지명 하이라이트 + 지도 패널
- **시각적 표시**: 본문 내 지명(예: `Damascus`, `다메섹`, `ダマスコ`)에 은은한 점선 밑줄과 작은 핀 아이콘(`📍`)을 표시합니다.
- **클릭 인터랙션**:
  - **데스크톱 (`>= 1024px`)**: 화면 우측(RTL일 경우 좌측)에 40% 너비의 **인터랙티브 지도 & 해설 사이드 패널**이 슬라이드 인 됩니다.
  - **모바일 (`< 1024px`)**: 화면 하단에서 **바텀 시트(Bottom Sheet)**가 올라오며, 드래그하여 절반 높이 또는 전체 화면으로 확장할 수 있습니다.
- **지명 상세 카드 구성**:
  1. **고대 ↔ 현대 지명 비교 배지**:
     - 예: `고대 지명: 다메섹 (Damascus)` ↔ `현대 위치: 시리아 다마스쿠스 (Damascus, Syria)`
     - 현대 국가 국기/지역 태그 및 위도·경도, 위치 비정 신뢰도(`확실함 / 유력함 / 추정`) 표시
  2. **인터랙티브 벡터 지도 (MapLibre GL JS)**:
     - 해당 지명으로 부드럽게 `flyTo` 이동 및 펄스 마커 강조
     - **레이어 토글**: 현대 국경/도시 지도 vs 고대 성경 지명 오버레이, 주변 주요 성경 지명 함께 보기
  3. **9개 언어 역사·지리 해설**:
     - 해당 지명의 지리적 특징(예: "안티레바논 산맥 동쪽 기슭의 오아시스 도시이자 대상 무역로의 요충지")
     - 성경 속 주요 사건 요약 (예: 아브라함의 종 엘리에셀, 나아만 장군, 사울(바울)의 회심과 직가(Straight Street))
     - 현재 모습 및 고고학적 의의
  4. **관련 성경 구절 바로가기**: 해당 지명이 등장하는 다른 대표 구절 목록 (클릭 시 해당 장으로 이동)

### 4.2 독립 성경 지도 탐색 (Atlas 탭)
본문 읽기와 별개로 상단 네비게이션의 **Atlas (성경 지도)** 탭에서 다음 기능을 제공합니다:
- **시대별 여정(Biblical Journeys) 오버레이**:
  - 족장 시대 (아브라함의 이동 경로: 우르 → 하란 → 가나안)
  - 출애굽 및 광야 40년 경로
  - 예수님의 공생애 사역지 (갈릴리 ↔ 예루살렘)
  - 사도 바울의 1·2·3차 선교 여행 및 로마 압송 경로
- **타임라인/스텝 내비게이션**: 여정의 각 경유지(Waypoint)를 순서대로 넘기며(`이전` / `다음`) 지도 이동 + 사건 해설 + 관련 성경 장 바로 열기 지원.
- **지명 검색**: 9개 언어 어떤 언어로 검색해도(예: "다메섹", "Damascus", "다마스쿠스") 해당 성경 지명을 찾아 지도로 이동.

## 5. MVP (Phase 1) vs 확장 (Phase 2) 범위

### Phase 1: Local-First PWA (MVP)
- Next.js App Router + TypeScript + Tailwind CSS 기반 반응형 PWA
- 9개 언어 UI 번역(`next-intl`) 및 `LTR / RTL / Vertical-RL` 읽기 엔진
- 하이브리드 `BibleProvider` (KJV 및 8개 언어 PD 역본 내장 + ESV/API.Bible 어댑터)
- 글씨 크기, 줄간격, 서체, 테마(Light/Sepia/Dark) 실시간 조절
- 본문 인라인 지명 연동 + MapLibre GL JS 지도 패널 + 독립 Atlas 탭 + 대표 여정 3종 이상
- IndexedDB(`Dexie.js`) 기반 로컬 저장: 북마크, 형광펜 하이라이트(4색), 개인 묵상 메모, 최근 읽은 위치, 오프라인 캐시

### Phase 2: 클라우드 동기화 & 모바일 앱 확장
- 사용자 계정 로그인(OAuth/Magic Link) 및 Supabase(PostgreSQL) 클라우드 동기화
- Capacitor를 활용한 iOS App Store / Android Google Play 네이티브 패키징
- 오디오 성경(TTS 또는 음성 스트리밍) 및 공동체 읽기표

## 6. 수용 기준 (Acceptance Criteria)
1. 앱 최초 진입 시 기본 언어는 영어(`en`), 기본 역본은 `KJV`(API 키 설정 시 `NIV/ESV/NRSV` 전환 가능)로 즉시 본문이 렌더링되어야 한다.
2. 언어를 `日本語(ja)`로 전환하면 본문이 `vertical-rl` 세로쓰기로 렌더링되고, `가로쓰기` 토글로 즉시 전환할 수 있어야 한다.
3. 언어를 `العربية(ar)`로 전환하면 전체 UI 레이아웃과 본문이 `dir="rtl"`로 미러링되어야 한다.
4. 본문에서 `Damascus`(다메섹) 등 지명을 클릭하면 지도 패널이 열리고, 고대 지명 ↔ 현대 지명(`Damascus, Syria`) 비교와 9개 언어 해설이 표시되어야 한다.
5. 글씨 크기 변경, 북마크, 하이라이트는 새로고침 및 오프라인 상태에서도 유지되어야 한다.
